# NANIWA – Design-Entwurf

Inoffizieller Design-Entwurf für die Webseite der Restaurants NANIWA Noodles & Soups und NANIWA Sushi & More in Düsseldorf. Nicht die offizielle Seite (die ist https://naniwa.de).

- `site/` – fertige statische Seite (Start mit Auswahl, `noodles/`, `sushi/`)
- `build.py` – erzeugt die drei HTML-Seiten: `python3 build.py`
- `data/` – Speisekarten als Daten

Lokal ansehen: `cd site && python3 -m http.server 4391`, dann http://localhost:4391
